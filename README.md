## Social-Media-Sentiment-Intelligence

An End to End ML-powered project that identifies positive, negative, and neutral sentiments from text data using simple NLP preprocessing.

## How to Run ?

1.Create a Virtual Environment

```bash
conda create -n sentiment python=3.11 -y
```

2. Activate the Environment

```bash
conda activate sentiment
```

3.install requirements.txt

```bash
pip install -r requirements.txt
```
